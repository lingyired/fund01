# 菜单栏 / 任务栏「历史」项 — 设计

日期：2026-09-16　分支：`feat/menubar-history-row`

## 目标

macOS 菜单栏与 Windows 任务栏新增一个**可选的全局实例「历史」**，一次性展示整个组合的
累计表现，不用点开 popup 才能看到。名称可自定义，下行数值可在三档之间切换：

1. 历史收益涨跌幅（累计收益率）
2. 历史收益额（累计收益金额）
3. 当前持仓额

## 数据来源（全部现成，无需新增请求）

`HoldingsSummary`（Rust `model.rs` / TS `holdingsCalc.ts`）已有：

| 展示档 | 字段 | 口径 |
| --- | --- | --- |
| 历史收益额 | `totalCumPnl` | 最新市值 − 成本；未录入成本时为 `null` |
| 历史收益涨跌幅 | `totalCumPnlPercent` | `(市值 − 成本) / 成本 × 100`；未录入成本时为 `null` |
| 当前持仓额 | `totalAmount` | 与 popup 顶部「持仓金额」同一个数（估值期按昨净值×份额、确认期按当日净值×份额） |

三者都已按 `overviewExcludedGroups` 的总览口径聚合（被排除分组不计入），与菜单栏「总览」实例同源。

## 设置项（`AppSettings` 新增 3 个）

| key | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `menubarHistoryEnabled` | `boolean` | `false` | 总开关。关=实例不存在 |
| `menubarHistoryLabel` | `string` | `'历史'` | 上行名称。trim；空串回落默认；超 8 字符截断 |
| `menubarHistoryMode` | `'cumPercent' \| 'cumAmount' \| 'holdingAmount'` | `'cumPercent'` | 下行数值档 |

⚠️ 三个字段都必须接入 **两端** 的归一化重建对象（`portfolioLogic.ts` 的 `normalizeConfig`
+ `portfolio.rs` 的 `normalize_config`），否则改其它设置时会被静默过滤（项目已知坑）。

## 实例

- id：`menubar-history`（常量 `INSTANCE_HISTORY`，与 `menubar-overview` 并列）
- 顺序：**排在最前**（历史 → 总览 → 分组 → 未分组）。macOS 可用 ⌘-拖拽调整；Windows 按此顺序。
- 复用两张现有 key 表（新增 `MENUBAR_HISTORY_KEY = '__history__'`）：
  - `menubarGroupColors` → 历史项上行文字自定义色
  - `menubarGroupSides` → 历史项在 Windows 任务栏的停靠侧
  - ⚠️ **不**写 `menubarHiddenGroups`：历史项的隐藏语义就是 `menubarHistoryEnabled = false`
- 开关关闭时实例从 `desired_instances()` 移除 → 真正销毁（与「总览永不销毁」不同，因为关闭状态
  由设置项持久化，无需靠实例存活保留菜单栏位置）。

## 展示规则

```
mode = holdingAmount            → format_holding_amount(totalAmount)，跟随上行色
mode = cumAmount  且 totalCumPnl ≠ null → format_amount(totalCumPnl)，按正负涨跌色
mode = cumPercent 且 totalCumPnlPercent ≠ null → format_pct(...)，按正负涨跌色
mode = cum*       且对应值为 null（未录入成本）→ 回退 format_holding_amount(totalAmount)，跟随上行色
行情快照未就绪（quote 为 None）   → 显示 "-"，跟随上行色
```

**颜色**：「历史收益」两档有涨跌语义 → 走涨跌色（涨红跌绿，沿用 `menubarRiseColor` /
`menubarFallColor` / `menubarFlatColor`）；「当前持仓额」及其回退没有涨跌语义 → **跟随上行色**
（即 `top_color_style` 的解析链：分组自定义色 → 全局上行色 → 系统默认色，深浅色自适应）。

**隐私模式**（`privacyMode = true`）沿用现有「菜单栏强制百分比」约定：

- `cumAmount` → 降级显示 `cumPercent`
- `holdingAmount`（含无成本回退）→ 显示 `****`

**格式化**：新增 `format_holding_amount`（菜单栏/任务栏专用，第 5 套，与既有四套互斥隔离）：
无方向符号，绝对值 ≥ 10 万用 `w` 缩写（整数不带小数），否则四舍五入到整数。

## 空态判定（两端 1:1 铁律）

`menubar_all_hidden`（Rust）/ `isMenubarEmpty`（TS）各加一条：

```
menubarHistoryEnabled == true → 菜单栏非空
```

## 交互

- macOS **⌘-拖出**历史实例 → 直接把 `menubarHistoryEnabled` 置 `false`（等价于在设置页关掉该项），
  不写入 `menubarHiddenGroups`。设置页开关随 config-change 实时同步。
- 右键菜单**不**给历史项挂「隐藏该分组」（与总览口径一致）。
- 点击历史实例 → 跳 popup 的「总览」tab（`popup_tab_for` 映射到 `'all'`）。

## Key 映射

- `group_key_of("menubar-history")` → `'__history__'`
- `instance_label("menubar-history")` → 设置里的自定义名称？
  否 —— 恒返回 `'历史'`（日志/菜单文案用固定名，避免用户改名后菜单项文案漂移）。

## 不做的（YAGNI）

- 不做「按分组的历史收益」行（分组实例仍只显示当日收益）
- Chrome 扩展不涉及（badge 单行）；设置项只出现在 tauri 的「菜单栏/任务栏」tab
