# 检查更新：服务端接入

Fund01 桌面版（Tauri）在打开设置界面时会检查一次是否有新版本。**服务端只需要放一个静态 JSON 文件**，无需任何服务端逻辑 / 数据库 / 接口开发，零维护成本。

## 一、客户端行为（了解即可）

- 触发时机：打开设置界面（每次都会检查，结果内存缓存 1 小时，1 小时内重复打开不再请求）。
- 请求地址：`GET https://lingai.net/fund01/version.json?v=1.2.0&os=macos&arch=arm64`，超时 10 秒。`v` 为客户端当前版本号（x.y.z）；`os` = `macos` / `windows`；`arch` = `x64` / `arm64`。**均为可忽略查询参数**（服务端可据此按平台分发下载地址 / 统计客户端版本与平台分布，纯静态文件托管时忽略即可）。
- 有更新：设置页「关于」区显示「发现新版本 vX.Y.Z」提示条 +「下载新版本」按钮，点击用系统浏览器打开 `downloadUrl`（缺省 fallback 打开项目主页）；`downloadUrl` 存在时另有「前往项目主页」按钮。
- 无更新 / 请求失败 / JSON 非法：完全静默，用户无感知。
- 不支持热更新：不会自动下载 / 安装新版本，只提示「下载新版本」（打开 downloadUrl）与「前往项目主页」。

## 二、JSON 格式

```json
{
  "latestVersion": "1.2.0",
  "homepage": "https://lingai.net/fund01",
  "downloadUrl": "https://lingai.net/fund01/Fund01_1.2.0_arm64.dmg"
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `latestVersion` | 是 | 最新已发布版本号，**必须为纯 `x.y.z` 三段数字**（如 `1.2.0`）。非数字或带后缀（如 `1.2.0-beta`）会被客户端判为「无更新」。发布新版本时同步更新。 |
| `homepage` | 否 | 「前往项目主页」按钮的跳转地址，缺省时客户端用 `https://lingai.net/fund01` 兜底。 |
| `downloadUrl` | 否 | 新版本下载地址。「下载新版本」按钮优先打开该地址；**缺省（不填）时 fallback 打开 `homepage`**；仅当该字段存在时才显示「前往项目主页」按钮（避免两个按钮指向同一地址）。 |

版本比较规则：按 `x.y.z` 逐段数字比较，仅当远端版本高于当前版本时提示。

## 三、文件放置位置

站点仓库：`/Users/lingsmbp/Documents/workspace/lingai-server/lingai.net`（Astro 静态站）。

Astro 的 `public/` 目录内容构建后**原样复制**到站点根（`dist/`），所以：

1. 新建文件 `public/fund01/version.json`（内容见上）；
2. 构建部署后即成为 `https://lingai.net/fund01/version.json`。

### ⚠️ 当前 `https://lingai.net/fund01` 返回 404

实测当前 `https://lingai.net/fund01` 是 nginx 404（Fund01 项目页实际在 `https://lingai.net/projects/fund01/`）。要让版本 JSON 与项目主页都在 `/fund01` 前缀下可达，需要在服务器（宝塔面板 / nginx）把 `/fund01` 指到站点静态目录：

- 方式一（推荐，nginx 配置）：在 lingai.net 站点配置中加一条 rewrite，把 `/fund01` 重写到 `/projects/fund01/`（项目主页）——此时 `version.json` 可放 `public/projects/fund01/version.json`（随项目页一起走构建部署）。
- 方式二：在站点根配置 `location /fund01/` 指向站点目录下的 `fund01/` 文件夹（nginx alias），`version.json` 放 `public/fund01/version.json`；如需 `/fund01` 不带斜杠也打开项目主页，再加一条 `location = /fund01` 的 301/302 重写到 `/fund01/`（或 `/projects/fund01/`）。

> 两种方式任选其一即可；客户端只认 `https://lingai.net/fund01/version.json` 这一个地址，路由配好后无需改客户端。

## 四、发布流程（发布新版本时）

1. 修改 `public/fund01/version.json`（或按上面方式一放在 `public/projects/fund01/version.json`）中的 `latestVersion` 为新版本号；
2. 走站点常规部署（`npm run build` 后推送，或宝塔面板更新）；
3. 验证：浏览器打开 `https://lingai.net/fund01/version.json` 应返回新 JSON。

### 低消耗捷径

站点是纯静态托管，**更新版本号可以不重跑构建**：直接登录服务器，把 `version.json` 文件覆盖到线上站点静态目录对应位置（宝塔面板文件管理即可，路径即站点根 `fund01/version.json`）。JSON 是静态文件，改完立即生效，无需重启任何服务。

## 五、容错约定（服务端无需处理）

- 客户端 10 秒超时，超时 / 网络失败 / 404 / JSON 解析失败 → 静默（不提示、不报错）。
- `latestVersion` 非法（非 `x.y.z` 数字）→ 保守判「无更新」。
- 缺 `homepage` → 用默认值 `https://lingai.net/fund01`。
