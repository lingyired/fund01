# Chrome Web Store 简介文案（fund01 基金盯盘）

> 面向普通用户的商店文案，无技术黑话。字段位置：Chrome Web Store 开发者后台 → 商品详情。

## 简短描述（Short description，≤132 字符）

基金持仓分组管理、盘中实时估值、收益盈亏与大盘黄金指数，红涨绿跌一目了然，打开即看。

## 详细描述（Detailed description）

**fund01 基金盯盘** —— 在浏览器里盯住你的基金。

一款轻量的基金盯盘扩展：管理持仓、看盘中估值、算收益盈亏，顺带盯一眼大盘和黄金。不用来回切换基金 App，打开浏览器就能看。

**持仓管理**

- 添加、编辑、删除持仓基金，可按「金额」或「份额」录入，支持批量编辑与一键导入

**持仓分组，各归各位**

- 持仓可按自己的逻辑归入多个分组——人工智能、海外投资、黄金……同一只基金还能按比例拆分到不同分组
- 分组可随时新增、重命名、删除，拖拽调整顺序
- popup 顶部按分组切换查看，每个分组显示当日收益方向（红赚绿亏）与收益详情，哪组赚钱、哪组亏钱一眼便知
- 支持分组收益汇总，可开启「分组 Tab 收益详情」，直接看当日收益率或收益金额

**盘中实时估值，红涨绿跌**

- 交易时段自动获取基金盘中估值，涨红跌绿，一眼看清今天赚了还是亏了
- 估值严格按官方净值口径计算，不与滞后的涨跌幅混淆

**收益盈亏一目了然**

- 每只基金显示持有收益（当前市值 − 成本本金），并汇总整体盈亏
- 持仓支持「日盈亏百分比 / 金额」两种展示方式，按习惯切换

**指数与行情面板**

- 大盘指数（上证、深证、创业板等）与美股指数随时可查
- 内置黄金看板（AU9999 / 国际金价 / COMEX 期货），金价涨跌扫一眼就知道
- 自选指数最多 5 个，常驻顶栏，一眼即得

**数据口径可信**

- 估值与净值日期标注清晰；QDII 基金按净值披露日对齐，盘中显示「-」，绝不用滞后涨幅冒充当日收益
- 数据来源为公开行情接口（天天基金 / 东方财富等），口径在设置页公开，不留黑箱

**体验细节**

- 深色 / 浅色 / 跟随系统三种主题，默认跟随系统
- 打开扩展立即展示最近一次行情，不用等待
- 所有数据仅保存在本地浏览器，不上传任何服务器
