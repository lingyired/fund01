# 测试流程：1.7.0 → 1.7.1 自动更新

**日期**：2026-10-12
**目的**：首次端到端验证 tauri-plugin-updater 全链路（这是发布前最后一道关）

---

## 前置：两个版本都装过公证包

| 版本 | 来源 |
|---|---|
| 1.7.0 | https://github.com/lingyired/fund01/releases/tag/v1.7.0 → `Fund01_1.7.0_arm64-ci.dmg` |
| 1.7.1 | 本次测试包（已放`~/Downloads/`）或正式 Release |

> ⚠️ **必须先装 1.7.0**，因为只有装了带 updater 的版本，才能被新清单触达。
> 1.6.x 及更早的老用户没有 updater，走的是 `version.json` 老通道。

---

## 测试步骤

### 1. 装 1.7.0 并确认版本

```bash
# 挂载 1.7.0 dmg，拖到应用程序
open ~/Downloads/Fund01_1.7.0_arm64-ci.dmg
# 拖 Fund01.app 到「应用程序」，**覆盖安装**

# 确认版本
defaults read /Applications/Fund01.app/Contents/Info.plist CFBundleShortVersionString
# 应输出：1.7.0
```

### 2. 确认 1.7.0 的 updater 是活的

打开 Fund01 → 设置 → 关于 → 点「检查更新」。

**预期**：显示「已是最新版本」（因为此时 latest.json 还是 1.7.0）。
这一步验证 updater 通道本身能通—— **如果这里报网络错误，说明端点拉不到清单**，后面的测试都免谈。

### 3. 发布 1.7.1（测试前由agent 完成）

latest.json 会被更新到 1.7.1。此时已装的 1.7.0 再点检查更新就应该发现新版本。

### 4. 测试自动更新 ⭐ 核心

1. 打开 Fund01 → 设置 → 关于 → 点「检查更新」
2. **应出现更新提示**：显示 1.7.1 + 更新说明「指数实时源修复…」
3. 点「立即更新」
4. **观察进度条**：应该出现下载进度百分比
5. 下载完成后**应用自动重启**

### 5. 验证升级结果

```bash
defaults read /Applications/Fund01.app/Contents/Info.plist CFBundleShortVersionString
# 应输出：1.7.1
```

再打开 popup 看指数面板 —— **5 个指数都应有数值**（这是 1.7.1 的核心修复）。

## 失败路径也要测（这些是真实场景，不是边角）

### A. 断网时点检查更新

**预期**：静默失败或友好提示，**不崩溃**、不卡死。

> 代码里对网络失败/JSON 非法/验签失败都是抛错由 UI 捕获静默处理，
> 且设置了 10s 超时（插件默认 None 会被黑洞连接无限挂起）。

### B. 点「立即更新」后观察进度

- 进度条应该动（不是一直 0%）
- 5.6MB~8.5MB 的包，本机应该几秒内下完

### C. 菜单栏 app 会被自动重启吗？

macOS 侧 Tauri updater **安装完成后自动重启应用**（Windows 是安装器自动退出）。
所以测试时menubar 图标会消失再出现，属正常。

## 关键观察点

| # | 观察 | 说明什么 |
|---|---|---|
| 1 | 检查更新能否拉到清单 | 端点可达性（lingai.net 404 → fallback 到 GitHub） |
| 2 | 是否识别出 1.7.1 | 版本号比较 + 清单结构是否正确 |
| 3 | 进度条是否动 | 事件回传 `fund01://update-progress` 是否通 |
| 4 | 是否自动重启 | `install_update` → relaunch 是否成功 |
| 5 | 版本是否变1.7.1 | 替换是否真的生效 |
| 6 | 指数是否有数值 | **1.7.1 的核心修复验证**（腾讯源 + 东财兜底） |
| 7 | 签名是否通过 | ed25519 验签；验签失败会明确报错而不是装坏包 |

---

## 失败时怎么查

| 现象 | 大概率原因 |
|---|---|
| 检查更新说已是最新，但 1.7.1 已发布 | latest.json 没更新 / 端点 1（lingai.net）返回了 200但内容是旧的 |
| 报网络错误 | 三个端点全挂（lingai.net 备份中 + GitHub 被墙 + gh-proxy 也挂） |
| 报 JSON 解析错误 | 清单格式不对（Tauri 在比对版本号**之前**就校验整个 JSON） |
| 报验签失败 | 签名密钥换了，或产物被改动 |
| 下载卡住不动 | 进度事件没回传（Rust → 前端事件链断） |
| 装完还是 1.7.0 | 安装没生效，检查 `/Applications` 权限（可能装到了别处） |

## 验证命令速查

```bash
# 当前安装版本
defaults read /Applications/Fund01.app/Contents/Info.plist CFBundleShortVersionString

# 签名与公证
codesign -dv /Applications/Fund01.app 2>&1 | grep -E "Authority|Signature"
spctl -a -vvv -t install /Applications/Fund01.app

# 清单文件（从 Release 下载，看线上真实内容）
gh api "repos/lingyired/fund01/releases/tags/v1.7.1" \
  --jq '.assets[] | select(.name=="latest.json") | .browser_download_url'
```

如果通过 → updater 全链路验证完成，以后每次发版都能走「应用内一键升级」。
如果不通过 → **别急着发**，把现象对照上面的「失败时怎么查」定位根因。
